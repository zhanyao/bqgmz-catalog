7. 比于圣人图设沟渠。沟渠满溢。流于深湖。故圣人不能拘通也。而人脉隆盛。入于八脉。而不还周。故十二经。亦不能拘之。其受邪气。蓄则肿热。砭射之也。（砭贬平声针石也）
8. 此亦承上章阳脉荣于六腑之义。言六腑属阳。邪在阳。则六腑不和。不和则气滞。而为聚为痈矣。下文又以脏腑并言之。以明其所以不和之故也。（聚字灵枢作痈字）
9. 故先揭而出之。以起下章诸邪之发病也。（后人言头痛不言死总结在后者非也）
