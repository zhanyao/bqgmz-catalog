2. 事见晁以道所为墓志中。明末盗伐其冢柏，顺治三年秋，知县济南张石只笃行谒墓下，复为封树立碑。其夜梦一青衣曰：“东坡遣致谢。”问：“先生今何在？”
3. 自小迎恩桥至此为草河支流，在南则接城河为“城清梵”矣。（详见《城北录》）
4. 献功楼五楹。联云：“青筐叶盖蚕应老（温庭筠），剪彩花时燕始飞（刘宪）。”
5. 水心亭在艳雪亭之侧，筑土为堵，一溪绕屋。联云：“杨柳风来潮未落（赵嘏），梧桐叶下雁初飞（杜牧）。”
6. 见悟堂在飞霞之左。联云：“花药绕方丈（常建），清流涌坐隅（元结）。”
7. 卢转运联云：“一代两文忠，到处风流标胜迹；三贤同俎豆，何人尚友似先生。”
8. 三清院在右岸砖路旁，高风冈以八分书题其门额，方士林东崖居之。林通五雷法，善治鬼，后为鬼魇，死于渡春桥水中。其徒黄鸣谦传其术。朱思堂运使赠联云：“炉火纯青销剑气，霜花欲白映仙根。”
9. 萧孝子墓在梅花书院之左，华表在市河西岸，有“奇孝可风”、“肝肠犹生”
10. 草堰陈周森，事母至孝，家贫，以舟为生，年二十未娶。母病革，祷宿于里中金龙大王庙。夜梦王坐殿上，颜色甚霁，谓曰：“尔母病用马肝一叶煎服可愈。”
