1. 第十三卷云：庾承仙，字崇光，颖川人也。再征为本州主簿，不出。又遣就拜，乃闭门幽遁，使者不得前也。
2. 第九卷云：齐建武二年，陶受勑东祈名山，困寻经典也。
3. 第十二卷云：孟智周，梁武帝时人也，多所该通。梁静惠王抚临神忮，请智周讲光宅寺，僧法云来，赴发讲法云渊解独步，甚相凌忽，及交往复盛其词辩，智周敷释焕然，僧众叹伏之也。
4. 第十四卷云：孙游岳，字玄达，东阳永康人也。却粒，饵麻屑、松与木。齐永明三年，敕征为兴世观主也。
5. 第十九卷云：徐师子，字德威，东海人也。陈武帝立宗虚大观，引师子以为观主。后六七年卒于馆，文皇勑责秘器并无，常与凡厥丧事皆取给台焉。
