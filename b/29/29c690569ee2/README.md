1. 《陶庐杂录》 清 法式善
2. 顺治十六年十二月，谕礼部：“前明崇祯帝励精图治十有七年，不幸寇乱国亡，身殉社稷。考其生平，无甚失德。遘兹厄运，殊堪矜恨。宜加谥号，以敦实行。今谥为庄烈愍皇帝。尔部即遵谕行。”
3. 《国朝江右八家诗选》，曾燠编。八家者，陈允衡、王猷定、曾畹、帅家相、蒋士铨、汪轫、杨、何在田。其自序云：“余汇钞江西历代诗，本朝得二百二十余人，八家盖杰出者也。”
4. 吕新吾曰，余少时曾泄当密之语，先君责之。对曰：“已戒闻者，使勿泄。”先君曰：“尔不能必尔之口，而能必人之口乎？且戒人与戒己孰难？小子慎之。”
5. 王阳明曰：“凡人言语正到快意时，便截然能忍默得。意气正到发扬时，便翕然能收敛得。忿怒嗜欲正到腾沸时，便廓然能消化得。此非天下大勇者不能。”
6. 林希元曰：“申报灾伤，与走报军机同限。失误饥民，与失误军机同罚。如此则人人知警。待哺之民，庶有济乎。”
7. 熙宁中，新法方行，州县骚然。邵康节闲居林下，门生故旧仕宦者，皆欲投劾而归。以书问康节。答曰：“正贤者所当尽力之时。新法固严，能宽一分，则民受一分之赐矣。投劾而去，何益。”
