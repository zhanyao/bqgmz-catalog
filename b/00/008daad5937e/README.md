1. 宋史卷一 本紀第一 太祖一
2. 一日，罷朝，坐便殿，不樂者久之。左右請其故。曰：「爾謂爲天子容易耶？早作乘快誤決一事，故不樂耳。」汴京新宮成，御正殿坐，令洞開諸門，謂左右曰：「此如我心，少有邪曲，人皆見之。」
3. 宋史卷四 本紀第四 太宗一
4. 冬十月辛未，以定難軍節度使趙保忠同平章事。以歲旱、彗星謫見，詔曰：「朕以身爲犧牲，焚於烈火，亦未足以答謝天譴。當與卿等審刑政之闕失、稼穡之艱難、恤物安人，以祈玄祐。」
5. 宋史卷六 本紀第六 真宗一
6. 六月乙亥，御紫宸殿按大安樂，觀宗廟祭器。丙戌，作集禧觀成。乙未，詔：「河北荐饑，轉運使察州縣長吏能招輯勞來者，上其狀；不稱職者，舉劾之。」
