7. 癸未，安西將軍鄧艾大破蜀大將姜維于上邽，詔曰：「兵未極武，醜虜摧破，斬首獲生，動以萬計，自頃戰克，無如此者。今遣使者犒賜將士，大會臨饗，飲宴終日，稱朕意焉。」
