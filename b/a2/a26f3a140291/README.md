## 章节目录（前 3 节）

1. 第三节看财官，若日月有气，官禄贵马龙常印绶诸吉生合日干者，乃官贵之命。若子孙妻财青龙常诸吉神临日合日者，乃富贵之之命也。凡子爻制则有官，如子爻见而无制则官，兄爻见无制则财薄。
2. 第四节论运限，凡日上旺相遇财官发福增产，遇鬼煞须防妈险，遇兄弟必主破财，若日衰遇官鬼则变官为鬼贼\，遇父母则变为艰辛，遇财福稍可发，遇兄弟则必遭祸患，看在何爻便断何年发作。
3. 第五节论寿数。寿数不可一概而论，若日上无气，遇官鬼大煞白虎丧门吊客在邪爻作党者，即知在何运中，遇之即死。日旺胜煞者不过灾病，一路平顺，一年一位细推详，夭寿贵贱从此决。
