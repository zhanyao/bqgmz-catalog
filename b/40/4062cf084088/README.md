3. 素洛春光潋滟平，千重媚脸初生。凌波罗袜势轻轻。烟笼日照，珠翠半分明。风引宝衣疑欲舞，鸾回凤翥堪惊。也知心许恐无成。陈王辞
4. 春病与春愁，何事年年有。半为枕前人，半为花间酒。醉金尊，摧玉手，共作鸳鸯偶。倒载卧云屏，雪面腰如柳。
5. 死又生，生又死，出没憧憧何日已。或前或后即差殊，一例无常归大地。
