4. 姑苏、姑胥、姑余，皆一地也。姑、胥、余并音同。《淮南览冥训》：「轶鹍鸡于姑余。」高诱注：「姑余，山名，在吴。」
5. 诗人爱用六朝，然能出新意者亦少。惟陈布衣毅《牛首山》诗极为警策，云：「似愁人世兴亡速，不肯回头望六朝。」
6. 高东井孝廉，高才不遇，所作诗亦时有愤时嫉俗之语。尝记其《观剧》一绝云：「曲江宴上探花回，试窘师门却费才。端莫轻他由窦客，许多卿相此中来。」
7. 李学士中简在上书房最久，诸皇子皆服其品学。乾隆乙酉岁秋，上偶以「鸠唤雨」命题，试内廷诸翰林，君诗最速成，中一联云：「愆阳犹可挽，拙性本无他。」
8. 北江诗话卷三
9. 成亲王工诗，年四十六，发已半白。尝有《夜坐》诗曰：「事繁书慰夜，心短睡辞人。」
10. 李明经御，字琴夫，诗有奇气，京口词人之冠也。尝见其《读战国策书后》九首之一云：「解纷如解玉连环，一笑飘然东海还。世上共求天下士，不知东海在人间。」
