## 章节目录（前 6 篇）

1. 晚间上山，师问：“汝今日在山下所见之物，可有心上思想他的否？”曰：“一切物都不想，只想那吃人的老虎，心上总觉舍他不得。”
2. 又云：“焚死之鬼五体不全，必觅伴合并而后能成形，或二三人合并不等。其并法：老不并少，男不并女。”
3. 先生《乌鲁木齐杂诗》有曰：“鸳鸯毕竟不双飞，天上人间旧愿违。白草萧萧埋旅榇，一生肠断华山畿。”
4. 旁观者曰：“尸非可换之物，而两营兵奇计如此，此非营兵之愚也，乃暗中鬼神之巧也。”
5. 或曰：“獭肝髓入医经。其势异若此，可为房中药，惜医经不载，而村人皆不之知也。”
6. 吴门顾君朗村是日过其地亲见之，并云土人称其下有龙宫，向一幼童误坠水，至一官署门坐二人对奕，状怪似虾蟹，见童讶之，询其故，送出水。幼童今现存，年甫三十余，尝向人谈此异。“
